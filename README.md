# hsjc 2.0 賽馬實戰雲端戰術看板 (官方旗艦版)

7×24 小時全天候運行的香港職業賽馬大戶暗盤資金流向監控系統。

## 核心功能
- **雙時刻落飛比對看板 (ResultForm 旗艦版)**：自動標記大戶落飛 TOP 3 警告卡片，紅綠雙色資金異動狀態燈。
- **2D 組合玩法交互式二維矩陣 (CompareForm 旗艦版)**：14×14 自適應網格展開，連贏/位置Q 賠率與大戶砸盤落飛熱力圖。
- **開鑼日 10 場全賽果復盤**：包含 121 匹馬頭馬派彩與詳細戰績。
- **明晚跑馬地夜賽排位表**：8 場 93 匹賽駒即時排位與評分負磅。

## 3分鐘一鍵免費上線 Render 指南

1. 在 GitHub 上新建倉庫：`hsjc-web`
2. 本地推送代碼：
   ```bash
   git remote add origin https://github.com/wangnanatom/hsjc-web.git
   git branch -M main
   git push -u origin main
   ```
3. 打開 [Render.com](https://dashboard.render.com/)，點擊 **New +** -> **Web Service**
4. 選擇關聯 GitHub 倉庫 `wangnanatom/hsjc-web`
5. 點擊 **Create Web Service**！Render 將在 2 分鐘內自動構建並生成永久專屬 HTTPS 網址！
